# EasiMart 模拟交易场玩法指南

## 1. 文档定位

本文档用于说明 EasiFi 平台中 EasiMart 模拟交易场的产品目标、参与方式、资产类别、基础交易流程以及可实践的典型套利玩法。

本文档面向以下读者：

1. 初次接触 RWA 抵押借贷的普通用户
2. 希望理解 EasiMart 玩法结构的产品、运营与市场人员
3. 计划基于平台进行策略研究、投资教育或模拟操盘展示的专业用户

## 2. 重要说明

1. EasiMart 是模拟交易场，所有 eU、eRWA、eCrypto 均为平台内测试用途的模拟代币，不代表真实资产所有权，也不具备真实货币价值。
2. EasiMart 的主要目标是帮助用户理解“以 RWA 或 Crypto 为抵押品进行借贷，再进行跨资产再投资和套利”的运作方式。
3. EasiMart 展示的是链上金融结构、风险收益逻辑与投资策略组合，不构成任何现实世界的投资建议、收益承诺或法律意见。
4. 平台中的价格、利率、抵押率、借贷期限、违约处理等机制，均用于模拟学习、策略验证和用户教育。

## 3. EasiMart 是什么

EasiMart 是 EasiFi 平台上的模拟交易场，核心用途不是单纯“买涨买跌”，而是让用户在 RWA 与 Crypto 两大类资产之间，体验抵押借贷、利差交易、再投资、杠杆放大和跨资产套利等更完整的链上金融玩法。

在传统投资中，收益往往主要来自单一资产价格上涨；在 EasiMart 中，用户可以将一种资产作为抵押品，借入另一种资产继续配置，从而在不同资产之间的价格波动差、收益率差和流动性差中寻找机会。

这意味着用户关注的不是单一标的是否上涨，而是：

1. 哪类资产更稳、适合作为抵押品
2. 哪类资产收益率更高、适合作为再投资目标
3. 哪两类资产的波动节奏不同、适合进行对冲或套利
4. 在给定贷款成本下，杠杆是否能够放大正向收益

## 4. 用户如何参与

### 4.1 注册与身份

1. 用户通过 EasiFi 网页版或 App 注册账户。
2. 用户需先完成 KYC，才可成为正式注册用户。
3. 用户提交的数字钱包地址，是其在平台中的唯一身份标识。

### 4.2 初始模拟资金

1. 每位新注册用户可获得平台赠送的 100,000 枚 eU。
2. eU 用于模拟 100,000 美元等值的测试资金。
3. eU 仅用于平台内模拟交易，不可提现，不具备真实价值。

### 4.3 用户可做的三类基础操作

1. 使用 eU 买入各类模拟 RWA 代币或模拟 Crypto 代币。
2. 持有资产后发起抵押借贷，放大投资或套利敞口。
3. 直接将 eU 或主流 eCrypto 用于放贷，赚取利息收益。

1. eNVDA
2. eAAPL
3. eGOOG
4. eTSLA
5. eBRK.A

这类资产更适合模拟成长型、行业主题型或事件驱动型投资判断。

### 5.3 稳健收益资产代币

1. 若干支 REITs 的 e 代币
2. 若干支汽车贷款 ABS 的 e 代币

这类资产更适合模拟“收益率覆盖借贷成本”的利差策略和低波动杠杆策略。

### 5.4 虚拟资产代币

1. eBTC
2. eETH
3. eSOL
4. eBNB
5. eOKB
6. eDOGE
7. eSHIB

这类资产通常波动更大，适合与稳健资产形成明显的风险差、收益差和套利机会。

## 6. 价格机制与市场特征

1. EasiMart 中所有模拟代币的价格与现实市场价格同步。
2. 不同资产的价格波动节奏并不同步，这是 EasiMart 玩法成立的基础。
3. 用户的交易逻辑不局限于“持有等待上涨”，而是可以围绕利率差、波动差、期限差和流动性差设计策略。

从策略角度看，EasiMart 最重要的不是“资产够多”，而是“资产之间差异够大”。

四类资产在以下几个维度存在显著差异：

1. 价格波动幅度
2. 市场流动性
3. 收益率水平
4. 风险承受预期
5. 对宏观事件和行业事件的敏感度

正是这些差异，使得平台具有模拟对冲、套利、杠杆增强和资产轮动策略的价值。

## 7. 模拟交易的基本流程

### 7.1 买入资产

用户可使用 eU 买入任意已开放的模拟资产，形成自己的基础持仓。

### 7.2 发起借贷撮合

持有 eRWA 的用户可将自己的代币挂牌，寻找愿意提供贷款的对手方。借贷双方可协商如下条件：

1. 抵押品种类
2. 抵押率
3. 贷款额度
4. 贷款利率
5. 借入的 Crypto 或 eU 种类
6. 借贷周期

### 7.3 借贷期限

测试阶段约定的借贷周期包括：

1. 1 分钟
2. 5 天
3. 10 天
4. 15 天
5. 30 天

其中 1 分钟周期主要用于快速体验完整交易闭环和策略验证；较长周期更适合模拟中短期投资判断与持仓管理。

### 7.4 智能合约执行

当借贷双方就条件达成一致后，即可调用 EasiFi 智能合约完成交易。平台通过智能合约自动执行：

1. 抵押品锁定
2. 借款发放
3. 到期结算
4. 利息支付
5. 违约处理

### 7.5 到期结果

1. 若借款人按时偿还本金和利息，则自动赎回自己的抵押资产。
2. 若借款人违约，则抵押的 eRWA 按约定规则自动转移给贷款人。

## 8. EasiMart 的玩法逻辑

EasiMart 的核心不在于“平台替用户交易”，而在于平台提供一个可验证、可学习、可比较的策略实验环境，让用户理解不同资产之间如何通过抵押借贷形成新型收益结构。

相比传统单资产交易，EasiMart 的玩法具有以下特征：

1. 收益来源更多元，不仅来自资产上涨，也来自利差、折价、期限和违约结果。
2. 杠杆来源更自然，是由“抵押后再投资”形成，而非单纯的高倍合约。
3. 风险更可拆分，用户可以单独判断抵押品风险、借款成本风险和再投资标的风险。
4. 更适合组合策略，因为稳健资产和高波动资产能够同时在链上配置和调仓。

## 9. 五种典型玩法指南

以下玩法按照杠杆使用程度和风险收益预期，由低到高进行排列。

### 9.1 玩法一：稳健放贷与折价接收抵押品

#### 玩法思路

用户优先寻找价格波动较小、流动性较好的 eRWA 作为抵押品，例如优质物业类 REITs。随后以贷款人的身份，为借款人提供贷款。

用户追求的核心收益包括：

1. 借贷利息收益
2. 借贷利率与银行同期存款利率之间的差额
3. 若借款人违约，则按折价获得抵押品的潜在收益

#### 适合人群

1. 偏好稳健收益的用户
2. 希望先熟悉平台借贷规则的初级用户
3. 不急于使用高杠杆的保守型策略用户

#### 关注重点

1. 抵押率是否足够安全
2. 借款利率是否覆盖资金占用成本
3. 抵押资产是否具备足够流动性
4. 若发生违约，自己是否愿意继续持有该类资产

#### 风险提示

1. 抵押品价格也可能下跌
2. 表面上低波动的资产，流动性不足时可能难以快速退出
3. 违约后获得抵押品不等于立即实现收益，仍需考虑二级流通与持有周期

### 9.2 玩法二：高分红稳健资产的循环贷放大

#### 玩法思路

用户选择具有稳定现金流、年化收益率较高且波动较小的 eRWA，例如优质 REITs。先用 eU 全额买入，再将该资产抵押借出新的 eU，继续买入同类资产，重复操作，形成循环贷。

该玩法的本质是：

1. 用资产收益率覆盖贷款利率
2. 用多轮抵押借贷放大配置规模
3. 在风险可控范围内增强总收益率

#### 适合人群

1. 理解杠杆机制、但不希望承担极端波动风险的用户
2. 想学习“收益资产加杠杆”模型的策略型用户

#### 关注重点

1. 目标资产年化收益率是否明显高于贷款利率
2. 单轮抵押率是否过高
3. 连续加杠杆后，总体回撤承受能力是否仍可接受
4. 是否设置了明确的停止加杠杆条件

#### 风险提示

1. 循环贷会放大收益，也会同步放大资产价格回撤
2. 即使目标资产波动较小，多轮放大后总风险并不低
3. 若收益率下降或利率上升，原本成立的利差可能快速收窄

### 9.3 玩法三：稳健抵押品加仓高弹性资产

#### 玩法思路

当用户明确判断某个高波动资产将明显上涨时，可先买入一类相对稳健、收益率又高于银行存款利率的 eRWA，再以该 eRWA 作为抵押品借出 eU，用借来的资金买入目标高波动资产。

这类玩法强调：

1. 用稳定资产承载融资能力
2. 用高弹性资产承载收益爆发力
3. 在不直接卖出现有稳健资产的前提下，追加风险资产仓位

#### 适合人群

1. 对某个成长型资产有较强判断的用户
2. 希望放大方向性收益，但仍保留部分稳健底仓的用户

#### 关注重点

1. 抵押品是否足够稳
2. 借款成本是否可控
3. 目标资产上涨空间是否足以覆盖融资成本与潜在回撤
4. 是否预先设定止盈和去杠杆条件

#### 风险提示

1. 高波动资产一旦判断错误，亏损会被融资放大
2. 抵押品和目标资产可能在极端行情中同时下跌
3. 若未及时止盈，账面盈利可能迅速回吐

### 9.4 玩法四：同向资产的双端杠杆增强

#### 玩法思路

当用户判断两种或多种资产将出现同步正向变化时，可以抵押预期涨幅较低的资产，去买入预期涨幅较高的资产。待两端资产同时上涨后，再统一卖出并结算。

该玩法的逻辑是把收益来源拆成两部分：

1. 抵押资产自身上涨
2. 借入后买入资产上涨更快

如果两端都判断正确，整体收益会高于单独持有任一资产。

#### 适合人群

1. 对相关资产存在联动判断能力的用户
2. 能够处理更复杂仓位结构的中高级用户

#### 关注重点

1. 两类资产是否真的具备同向联动关系
2. 预期涨幅差是否足够覆盖借贷成本
3. 一旦相关性失效，是否有明确退出计划

#### 风险提示

1. 同向关系并非总是成立
2. 两端同时加杠杆，本质上会放大组合波动
3. 若两端涨跌节奏错位，可能出现“判断方向正确但交易结果不佳”的情况

### 9.5 玩法五：反向资产下的高风险激进策略

#### 玩法思路

当用户判断两类资产将明显反向运行时，可抵押预期下跌幅度较低的资产，买入预期上涨幅度较高的资产，利用资产之间的强烈分化去追求更高收益。

在模拟环境中，该玩法也可用于观察“违约处理规则、抵押品转移机制、组合收益与损失路径”如何影响最终结果，因此它更适合作为风险教育和机制理解的实验场景。

#### 适合人群

1. 已熟悉平台规则的高级用户
2. 重点研究风险结构、违约后果和极端场景收益分布的策略研究者

#### 关注重点

1. 对冲逻辑是否真实成立
2. 违约成本、抵押品损失与组合盈利之间的关系是否清晰
3. 是否把该玩法当作机制推演，而非简单追求高收益

#### 风险提示

1. 这是高风险玩法，不适合作为新手入门策略
2. 一旦市场判断错误，损失可能快速放大
3. 任何涉及违约后果推演的操作，都应仅限于模拟环境中的机制学习与压力测试

## 10. 新手建议的参与路径

为了帮助用户逐步理解 EasiMart，建议按以下顺序体验：

1. 先使用 eU 买入少量稳健资产，理解价格、持仓和资产切换。
2. 再尝试以贷款人身份参与一笔短周期借贷，熟悉抵押率、利率和到期交割。
3. 然后体验玩法一和玩法二，理解“利差”和“循环贷”的基本结构。
4. 在熟悉风险后，再尝试玩法三和玩法四。
5. 将玩法五仅作为高风险情境推演与规则理解，不建议作为入门路径。

## 11. EasiM-Agent 的作用

EasiM-Agent 是 EasiFi 为用户提供的财经信息汇总分析及投资决策 Agent，用于协助用户在多资产环境中识别机会、管理风险和优化组合。

在 EasiMart 的场景中，EasiM-Agent 的价值主要体现在：

1. 汇总多类资产的市场信息与价格变化
2. 分析不同资产之间的相关性、收益率差和波动差
3. 提供组合配置建议
4. 在条件成熟时，支持自动代理执行套利思路

由于跨资产套利需要同时处理多个变量，例如价格波动、融资成本、期限结构和仓位风险，人工判断往往效率较低，Agent 因此成为平台中重要的决策辅助工具。

在 EasiFi 正式上线后，调用 EasiM-Agent 需支付平台币 Easy。用户也可通过参与平台抵押借贷获取 Easy 奖励，具体以平台后续公布的代币经济规则为准。

## 12. 专业投资代理与排行榜机制

EasiFi 在测试阶段将逐步引入不同类型的专业投资参与者，例如：

1. 传统机构投资经理人
2. 量化交易经理人
3. 对冲基金经理人
4. 高风险偏好的加密投资人

这些参与者将使用等量的 eU，在同一模拟环境中展示各自的投资策略、仓位管理方式和操盘风格。

平台计划按以下周期公布模拟收益排行榜：

1. 24 小时
2. 3 天
3. 10 天
4. 1 个月

排行榜将以 eU 计价的收益表现作为主要参考，用于展示不同用户与机构的策略能力，并对优秀成绩者给予奖励。

当平台发展成熟后，还可进一步开放：

1. 跟单功能
2. 一键复制投资人的模拟策略
3. 通过 API 外接正式交易所进行真实交易

## 13. EasiMart 的核心价值总结

EasiMart 的意义不在于简单模拟买卖，而在于把原本分散在传统金融和加密金融中的几类能力放到同一个链上实验场中：

1. RWA 持有与配置
2. 抵押借贷
3. 利差交易
4. 跨资产套利
5. 杠杆增强
6. 策略展示与跟随

对用户而言，EasiMart 是学习新型链上投资结构的模拟环境；对平台而言，EasiMart 是连接 RWA、Crypto、Agent 决策与未来跟单生态的重要入口。

## 14. 使用本文档的建议方式

阅读本文档时，建议用户不要把五种玩法当作孤立动作，而应从以下四个问题出发理解平台：

1. 我用什么资产做底仓
2. 我用什么资产做抵押
3. 我借入什么资产继续投资
4. 我的预期收益是否足以覆盖借贷成本和风险暴露

只要用户能持续围绕这四个问题进行判断，就能逐步掌握 EasiMart 的玩法本质。
