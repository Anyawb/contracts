Easy代币经济学白皮书
         ——EasiFi 抵押借贷协议的平台治理代币说明

一、项目概述

1.1 项目背景
      当前全球WEB3.0市场快速发展，现实资产代币化（RWA）、AI 智能投顾、去中心化金融（DeFi）已成为行业核心发展方向。
      但是已上链的RWA代币大多数又在链上沉淀，缺乏二级市场交易造成流动性缺失，而其稳定收益可对冲加密货币高波动性的显著金融特性，未能在DeFi领域充分发挥作用，成为阻碍RWA发展的最大障碍。

1.2 EasiFi 协议定位
      EasiFi 是开源的去中心化抵押借贷协议，在全品类RWA代币和主流稳定币及加密货币之间搭建流动性桥梁，为用户提供安全、高效、透明的DeFi服务。EasiFi同时还拥有EasiM智能行情分析系统、EasiMart 模拟交易场、API对接外部交易等功能模块，将抵押借贷、模拟交易、智能投顾、策略外调等打通形成全场景金融服务，是RWA产业必备的基础设施。

1.3 EasiFi的治理代币Easy
      Easy 作为 EasiFi 协议的唯一平台治理与生态流通代币，核心目标是连接用户行为与生态价值，让平台的所有抵押借贷参与者同时成为建设者和治理者，共享平台发展的红利。
      用户在EasiFi参与抵押借贷既可获得Easy奖励，而在调用EasiM智能分析、参与RWA vs Crypto 间模拟交易、将EasiM生成的交易策略通过API调往外部交易所等，均需以Easy作为支付手段。
      用户持有的Easy还代表了平台治理决策的投票权，参与表决EasiFi的重要决策，共同推动 EasiFi 逐步向完全去中心化自治组织（DAO）演进。

三、Easy的发行规则

3.1 发币触发条件：每笔借贷完成，平台扣除手续费后，自动铸币发行，作为奖励平分给借贷双方。

3.2 借贷额度：单笔借贷额最低 1000U，上不封顶

3.3 借贷手续费：借贷总额 0.06%，借贷双方各承担 0.03%

3.4 借贷奖励Easy：
启动红利期（平台累计借贷总额＜1亿U），每 1000U 借贷额度 → 发行并奖励 10 个 Easy，借贷双方各5个。
公式：单笔发行数量 = 借贷额度 ÷ 1000 × 10。

通缩启动后（平台累计借贷总额≥1亿U），新发行Easy数量与链上留存Easy数量负相关，留存越多，新发越少。
公式：单笔新增发行数量 = 借贷额度 ÷ 100 ÷ (1 + 10⁻⁷ × 留存Easy总数)，其中10⁻⁷为平台设定的通缩系数。
3.5 机制设计：鼓励用户高额度、多频次参与借贷，越早参与获得的红利越高，持有的Easy代币因通缩机制而不断升值。

四、Easy的获得

4.1 用户参与平台的抵押借贷，起始阶段每参与借贷1000U，借贷双方各获得5个Easy的奖励。

4.2 进入通缩机制启动期后，用户参与借贷获得的Easy依照下面的公式计算：
    单笔借贷新增发Easy个数 = 单笔借贷额度 ÷ 100 ÷ (1 + 10⁻⁷× 链上留存Easy总数)

4.3 参与模拟交易成绩优秀获奖
      用户参与平台的模拟交易场EasiMart（另文详细介绍）交易，在模拟 RWA 代币vs模拟虚拟币间抵押借贷投资交易的各类收益排行榜中，获得优胜名次者可获得对应额度 的Easy 奖励，奖励定期结算发放。

4. 4 参与生态建设任务获奖
      用户参与平台的社区推广、生态维护、内容建设、治理提案、测试反馈等公开任务，经社区审核通过后，可获得平台公示额度的 Easy 奖励。平台任务体系的运作由社区共同监督。

4.5 二级市场购买
      EasiFi平台本身不提供Easy的销售及交易，用户可通过平台外的去中心化交易所（DEX）及合规交易平台自行购买 Easy。平台对此不支持、不干预、不禁止，所有二级市场交易风险均由用户自行承担。

五、Easy 的使用与消耗
      Easy 为 EasiFi 生态内唯一功能支付与服务使用的通证，核心使用场景如下：

5.1 EasiM智能信息分析及决策的调用
      EasiM是EasiFi平台研发的财经信息汇总分析及投资决策Agent（另文详细介绍），用户每调用一次EasiM服务，需支付一个Easy作为服务费用。

5.2 EasiMart 模拟交易场使用
      EasiMart是EasiFi设立的链上跨品类代币综合交易模拟场，用户在 EasiMart 需使用模拟美元代币eU购买场内的各类模拟 RWA 代币或模拟虚拟币，参照EasiM提供的信息分析和决策建议，开展抵押借贷套利交易的模拟操作。（具体操作详见《EasiMart使用说明》）
      通过KYC新注册的用户均可获得平台免费赠送的10万个eU。用户在模拟交易中损失eU后，可使用Easy在平台换取eU，1Easy=100eU。
      模拟交易的赢亏均以eU结算，平台设置不同形式、不同周期的多类投资收益排行榜，优胜者将获得不同额度的 Easy 奖励。

5.3  交易策略 API 外调服务
      用户在 EasiMart 模拟场通过演练调整自认为成熟的交易策略，可通过平台 API 一键对外接入主流交易平台进行真实交易，调用API一次需支付1个 Easy 作为使用费。

六、回收Easy的销毁与分配

6.1 回收来源：用户调用平台的EasiM智能投顾Agent及调用API外接交易所，每次需支付1个Easy，转入平台的回收钱包。

6.2 回收钱包定期将其中75%的 Easy 永久销毁，体现Easy的通缩机制。

6.3 回收钱包将剩余的 25% 作为生态奖励，其中15% 奖励给平台运营维护团队，10% 奖励给参与平台生态建设的用户。

6.4 回收Easy的销毁和分配全流程由链上智能合约自动执行，公开透明

七、Easy与平台治理

7.1 治理基础规则

      Easy 代币是 EasiFi 协议的唯一治理凭证，持有并质押 Easy 代币的用户，可参与平台链上治理投票。

7.2 投票权重规则

      用户投票权重严格按照质押的 Easy 代币额度比例确认，质押额度越高，治理权重越大，实现“权益与贡献匹配”的去中心化治理原则。

7.3 DAO 过渡计划

      当平台用户数量、TVL（总锁仓价值） 达到约定规模后，EasiFi 将逐步向完全去中心化自治组织（DAO）过渡，由用户采用质押Easi数量获得的投票权，投票表决下述平台的重大决策：

1）协议核心参数（借贷利率、抵押率、风控规则、资产准入等）全部开放社区投票；

2）生态基金使用、功能升级、合作接入等重大决策由社区投票决定；

3）团队权限逐步下放，最终实现社区自主运营、自主维护、自主决策。

八、风险提示

8.1 区块链技术风险：智能合约漏洞、公链拥堵、黑客攻击等潜在技术风险；

8.2 市场波动风险：Easy 代币二级市场价格存在大幅波动可能，无保值承诺；

8.3 政策合规风险：不同国家与地区对加密资产、DeFi 协议监管政策存在差异；

8.4 流动性风险：代币二级市场流动性受市场环境影响，存在交易滑点风险；

8.5 用户责任风险：用户需妥善保管钱包私钥，因私钥丢失、误操作导致的损失由用户自行承担。
